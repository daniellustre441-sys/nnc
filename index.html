// About North Negros College

Pioneering holistic education and technological excellence in Negros Island.

North Negros College is committed to providing students with quality education and preparing them for successful careers in a tech-driven world. The institution promotes academic excellence, leadership, discipline, responsibility, and cutting-edge technological innovation within a dynamic learning ecosystem.

// Bachelor of Science in Computer Science

A premier 4-year degree engineered for mastering modern tech stacks, algorithms, and systems.

BSCS is a rigorous program focused on advanced programming, software engineering, intelligent systems, database architecture, network security, and emerging digital technologies.

Core Competencies & Modules

Core Development

  • Advanced Programming Languages
  • Full-Stack Web & Mobile Applications
  • Software Engineering Methodologies
  • Data Structures & Complex Algorithms
  • Database Management & Cloud Architecture

Advanced Tech & Systems

  • Artificial Intelligence & Machine Learning
  • Cybersecurity & Network Defense
  • Cloud Computing & DevOps Pipelines
  • System Analysis & Problem Solving
  • Enterprise Project Experience
